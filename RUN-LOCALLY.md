# Как запустить Lumi у себя на Mac

Проект — `Lumi.swiftpm`, формат Swift Playgrounds App. Работает **только на
macOS** (через Xcode или приложение Swift Playgrounds) — на Windows/Linux
собрать не получится, там нет нужных Apple-инструментов.

---

## Что понадобится

- **Mac** с macOS 14 (Sonoma) или новее.
- **Xcode 15+** из Mac App Store (бесплатно). Либо, как альтернатива —
  приложение **Swift Playgrounds** (тоже бесплатно, тоже из Mac App Store).
- Никакого платного Apple Developer аккаунта не нужно — запуск в
  симуляторе iPhone работает без него.

---

## Способ 1 — через Xcode (рекомендую, виднее ошибки)

### 1. Скачать код

Через терминал (приложение "Терминал" на Mac):

```bash
git clone https://github.com/maratfaiz/lumidesign.git
cd lumidesign
git checkout claude/ios-app-from-html-9elfn3
```

Если git не установлен — Mac сам предложит поставить Command Line Tools,
подтверди установку.

Либо без терминала: на странице
`https://github.com/maratfaiz/lumidesign/tree/claude/ios-app-from-html-9elfn3`
нажать зелёную кнопку **Code → Download ZIP** и распаковать архив.

### 2. Открыть проект

В Finder зайти в папку `lumidesign`, дважды кликнуть на **`Lumi.swiftpm`**
(это папка, но с особым значком — Xcode откроет её как проект). Либо в
самом Xcode: **File → Open…** и выбрать папку `Lumi.swiftpm`.

Xcode пару секунд "подтянет" пакет (индексация SwiftPM) — подожди, пока
внизу пропадёт прогресс-бар.

### 3. Выбрать симулятор

Вверху окна Xcode, рядом с кнопкой ▶️ (Run) — выпадающий список устройств.
Выбери любой iPhone (например **iPhone 15**). Если такого симулятора ещё
нет — Xcode предложит скачать его автоматически (потребуется Wi-Fi,
~5-8 ГБ, один раз).

### 4. Запустить

Нажать ▶️ (или `Cmd + R`). Первая сборка займёт 30-60 секунд. Откроется
симулятор iPhone с запущенным приложением Lumi.

### Если сборка упала с ошибкой

Открой панель ошибок (значок ⚠️ слева вверху или `Cmd + 5`), там будет
конкретная строка кода. Пришли мне текст ошибки — я это не могу
проверить сама (нет macOS в моей среде), поэтому решаем по факту.

## Способ 2 — через приложение Swift Playgrounds

Проще, но без подробных сообщений об ошибках.

1. Установи **Swift Playgrounds** из Mac App Store.
2. Скачай код (см. шаг 1 выше — клонировать или скачать ZIP).
3. В Finder дважды кликни на `Lumi.swiftpm` — если Swift Playgrounds
   стоит, macOS предложит открыть именно в нём (или выбери вручную:
   правый клик → Open With → Playgrounds).
4. Нажми ▶️ **Run My App** внизу экрана.

---

## Что проверять

- **Полный флоу**: заставка → приветствие → онбординг (4 вопроса) →
  экран "план готов" → первый урок → "серия начата" → главный экран.
- **Таб-бар** снизу: должен быть только на Главном/Курсах/Профиле,
  на остальных экранах — кнопка "←" назад.
- **Маскот**: на заставке, приветствии, главном экране, профиле и т.д.
  должна быть жёлтая звёздочка (не серый плейсхолдер-кружок с иконкой —
  если видишь кружок вместо звёздочки, значит картинка не подгрузилась,
  сообщи мне).
- **Иконки**: огонёк/монетка/снежинка вверху главного экрана, иконки в
  магазине, ачивках и т.д. — должны быть чёрным силуэтом Phosphor,
  прокрашенным в нужный цвет (не серый системный символ Apple).
- **Настройки → "Все экраны (демо)"** — короткий путь, чтобы проверить
  вообще все экраны подряд, не проходя весь флоу вручную.
- **Рабочие практики**: Дыхание (таймер 4-7-8), Аффирмации (карусель),
  Медитация (таймер + выбор атмосферы) — должны реально считать, не быть
  статичной картинкой.

Если что-то не так — присылай скриншот и я поправлю в коде.
